## Ограничение доступа к данным

Сайты tbank.ru, alfabank.ru и uralsib.ru обслуживаются по сертификатам «Russian Trusted Root CA» (Минцифры РФ); до установки корневого сертификата загрузка страниц прерывалась ошибкой проверки TLS.

**Следствие.** Данные Т-Банка и Уралсиба получены напрямую с живых страниц и из официальных тарифных документов. Условия Альфа-Банка взяты из официального тарифного документа «Тарифы по эквайрингу», действующего с 21.10.2026.

**Обязательный ручной шаг.** Подтвердить у ЮKassa состав вознаграждения за сервис чеков и режим НДС по нему: публичные тарифы раздельный режим НДС не определяют.
