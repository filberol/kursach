## Ограничение доступа к данным

Сайты tbank.ru, alfabank.ru и uralsib.ru обслуживаются по сертификатам, выпущенным 'Russian Trusted Root CA' (Минцифры РФ). Этот корневой сертификат отсутствует в стандартных хранилищах доверия, поэтому автоматическая загрузка страниц возвращала ошибку проверки TLS (code 19, self-signed certificate in certificate chain).

**Следствие.** Данные Т-Банка и Альфа-Банка получены из датированных снимков Архива Интернета (web.archive.org), а не с живых страниц. Данные ЮKassa и Банка России получены напрямую.

**Обязательный ручной шаг.** Каждую ставку необходимо повторно сверить с живым официальным тарифным документом (PDF) перед сдачей работы. См. docs/registry.md, раздел 'Ручная доверификация'.

- Отраслевая дифференциация ставок («комиссия отличается для разных отраслей бизнеса») без указания конкретных значений.
